# 极速购物流配送说明

## 一、配送方式

极速购提供多种配送方式，根据商品类型和用户所在地自动匹配最优物流。

### 1. 快递合作商

| 快递公司 | 覆盖区域 | 预计时效 | 适用场景 |
|----------|---------|---------|---------|
| 顺丰速运 | 全国（含偏远地区） | 1-3 天 | 高价值商品、电子产品 |
| 京东物流 | 全国主要城市 | 1-2 天 | 大件商品、次日达区域 |
| 圆通速递 | 全国 | 2-4 天 | 普通商品、偏远地区 |
| 中通快递 | 全国 | 2-4 天 | 普通商品 |

### 2. 配送方式选择

- **标准配送**：免费，匹配最优快递（3-5 天到达）
- **快速配送**：¥10，顺丰/京东发货（1-3 天到达）
- **次日达**：¥20，部分城市支持（下单后次日 18 点前送达）
- **定时配送**：¥15，可指定工作日或周末送达

### 3. 自提服务

- 支持菜鸟驿站、丰巢快递柜自提
- 下单时可选附近自提点
- 包裹到达自提点后免费保管 3 天，超期收取 ¥1/天保管费

## 二、发货时效

### 1. 正常发货时效

| 订单状态 | 发货时效 |
|----------|---------|
| 待付款 | 付款后 24 小时内发货 |
| 已付款 | 24 小时内发货（工作日） |
| 预售商品 | 按商品页面标注的发货时间 |

## 三、物流跟踪

### 1. 物流信息查询

- 订单发货后，系统自动推送短信通知（含快递单号）
- 可在「我的订单」中查看物流轨迹
- 关注极速购公众号，绑定手机号后自动推送物流更新

### 2. 物流状态说明

| 状态 | 含义 |
|------|------|
| 已揽收 | 快递员已取件 |
| 运输中 | 包裹在转运途中 |
| 到达转运中心 | 包裹到达分拨中心，等待分拣 |
| 派件中 | 快递员正在派送 |
| 已签收 | 包裹已被签收 |
| 派件失败 | 联系不上收件人，将再次派送 |

### 3. 物流异常处理

- **超过预计时效未到达**：联系客服查询，超时可申请补偿
- **包裹破损**：当面拒签或签收后 48 小时内联系客服
- **包裹丢失**：极速购补发或退款
- **地址错误**：联系客服拦截修改，可能产生额外运费

## 四、运费规则

### 1. 运费标准

| 商品金额 | 运费 |
|----------|------|
| ¥0 - ¥49 | ¥8 |
| ¥50 - ¥99 | ¥5 |
| ¥100 以上 | 免费 |

### 2. 偏远地区附加费

以下地区需加收 ¥10-20 偏远地区运费：

- 新疆、西藏、青海、内蒙古部分地区
- 港澳台地区（需另付跨境运费）
- 偏远海岛、山区

### 3. 运费优惠

- 新用户首单免运费
- 会员用户全场免运费
- 满减活动期间，达到门槛免运费

## 五、签收说明

### 1. 签收前检查

- 确认包裹外观无破损、无拆封痕迹
- 确认包裹数量与订单一致
- 贵重商品建议当面验货

### 2. 代签收说明

- 快递柜、驿站签收视为本人签收
- 门卫、前台代签收需用户自行前往领取
- 他人代签收产生的丢失/损坏，由用户自行处理

### 3. 拒签说明

- 包裹破损可拒签，快递退回后全额退款
- 非质量问题拒签，需承担来回运费
- 多次拒签可能影响后续购物体验

---

## 六、配送时效保障

### 1. 延迟赔付

- 超过承诺时效 3 天未送达，补偿 ¥10 无门槛券
- 超过承诺时效 7 天未送达，全额退款 + ¥20 补偿券

### 2. 不可抗力

以下情况不属于延迟赔付范围：

- 自然灾害（台风、暴雨、地震等）
- 交通管制、道路封闭
- 大型活动期间交通限制
- 国家法定节假日

### 3. 物流投诉

- 快递服务态度问题：联系极速购客服反馈
- 快递丢失/损坏：极速购先行赔付，后向快递公司追偿
- 配送地址不在服务范围：全额退款
